# Update guide report data

This regenerates the report's data files from the FreeSpirit Google Sheets,
using the extraction scripts in `.claude/skills/update-guide-report/scripts/`. There are two sources:

- **Tour data** ("1.1 Evidencija prodaje"): you download the workbook by hand.
  The script builds `data-2025.js` and `data-2026.js`, including the PAID side
  of the Bookings tab.
- **FREE channel data** ("1.2 Booking channels OTA"): Claude pulls it through
  the Google Drive connector. You don't download it.

No rebuild needed. Every `data-*.js` file is loaded as its own `<script>` tag,
not bundled into `dist/app.js`, so a data-only update never touches app code.

Do not copy in the data files generated by evidencija. They lack
`paidChannelStats`, which silently turns the Bookings PAID section into
"not available". Always regenerate with `.claude/skills/update-guide-report/scripts/extract_guides.py`.

## One-time setup (per computer)

0. **Get the report files.** The skill needs the report's data files, `index.html`,
   `dist/` and the skill itself. Download only those with a sparse clone (about 9 MB,
   the rest of the repo is skipped). Run this where you want the folder to live:

   ```
   git clone --filter=blob:none --sparse https://github.com/JuraFST/freespirit-jura-guide-report.git
   cd freespirit-jura-guide-report
   git sparse-checkout set --no-cone /index.html /report.css /dist/ /data-2025.js /data-2026.js /data-channels-2025.js /data-channels-2026.js /data-guide-notes.js /last-update.js /freespirit_logo_crop.jpg /favicon.png /favicon.ico /.claude/skills/update-guide-report/
   ```

   Open Claude in that `freespirit-jura-guide-report` folder. Later updates: `git pull` in the same folder.


1. Install Python 3 if not already installed:
   - **macOS:** `brew install python3`
   - **Windows (Git Bash):** `winget install Python.Python.3.12`
2. Install the dependency the tour-data script needs (the Bookings channel
   script needs nothing extra):

   ```
   pip3 install -r .claude/skills/update-guide-report/requirements.txt
   ```

## Tour data (Guides, Financial, Paid Bookings)

### 1. Download the latest sheet

Open the FreeSpirit Google Sheet ("1.1 Evidencija prodaje") in your browser,
then **File → Download → Microsoft Excel (.xlsx)**.

Move the file into this project folder and rename it to exactly:

```
1.1 Evidencija prodaje 26.xlsx
```

The workbook has one `Evidencija` tab. Both years live in it, split by the
`Year` column. There is no `Evidencija_25` tab.

### 2. Back up the current data

```
cp data-2025.js .backup-data-2025-$(date +%Y%m%d-%H%M%S).js
cp data-2026.js .backup-data-2026-$(date +%Y%m%d-%H%M%S).js
```

### 3. Regenerate into `.new` files

Write to `.new` files first. A failed run must never leave the live file empty.

```
python3 .claude/skills/update-guide-report/scripts/extract_guides.py --year 2026 > data-2026.js.new
python3 .claude/skills/update-guide-report/scripts/extract_guides.py --year 2025 --sheet Evidencija > data-2025.js.new
grep -q "paidChannelStats26" data-2026.js.new && grep -q "paidChannelStats25" data-2025.js.new
```

The `--sheet Evidencija` on the 2025 line is required. Without it the script
looks for an `Evidencija_25` tab and stops with
`KeyError: Worksheet Evidencija_25 does not exist`.

2025 is a closed year. Only regenerate it when correcting historical data.

If the `grep` fails or either command exits with an error, stop. Delete the
`.new` files and keep the current data.

### 4. Sanity-check, then replace

- Compare `kpiTotals26` in the old and new `data-2026.js`. If `guides` drops
  sharply or a total hits zero, stop.
- `paidChannelStats26` should sum to about `kpiTotals26.paidPax` (within a
  percent or two, not exact).

Only then:

```
mv data-2025.js.new data-2025.js
mv data-2026.js.new data-2026.js
rm "1.1 Evidencija prodaje 26.xlsx"
```

### 5. Update the "last updated" date

In `last-update.js`, set `REPORT_LAST_UPDATE` to the latest date that has
data, not necessarily today. Find the latest `m-d` key in any guide's `byDay`
in the new `data-2026.js`, and cap it at today. If you set it to today, the
Guides TOTAL can show stale numbers.

### 6. Verify in a browser

Open `index.html` directly (double-click it) and check:

- The 2026 TOTAL on the Guides tab (Free tours, Paid tours, pax, Total Tours)
  equals `kpiTotals26`.
- Total Tours 2026 is about `freeTours + paidTours`. A few tours off is
  cutoff timing. A large gap is a problem.
- The Bookings tab's **Paid** section shows numbers, not "not available".

### 7. Commit and push

```
git add data-2025.js data-2026.js last-update.js
git commit -m "Update guide data $(date +%Y-%m)"
git push
```

Reload https://jurafst.github.io/freespirit-jura-guide-report/ after about a
minute to confirm it's live.

## FREE channel data (Bookings tab, Free section)

This is separate from the tour data. It comes from a different sheet.

**One-time check:** Google Drive must be connected in Claude (Settings →
Connectors → Google Drive). If it isn't, Claude will say so. Connect it once
and run again.

Source: Google Sheet "1.2 Booking channels OTA", Drive file id
`1u6yHl1wKOScMfSLYMgyAD0jWnWRgITXawtuJDJCcDFE`. Use this file id. Don't
search by title: copies of the same sheet exist, owned by other accounts.
Only the `stg_checked_in` tab is used.

### 1. Back up

```
cp data-channels-2026.js .backup-data-channels-2026-$(date +%Y%m%d-%H%M%S).js
```

### 2. Pull the sheet and regenerate

- Call the Drive connector's `download_file_content` with that file id and
  `exportMimeType: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`.
  The result is large and saves to a tool-result file. Decode its base64
  `content` field and write the bytes to `1.2 Booking channels OTA.xlsx` in
  this folder. Use a short Python snippet (`json.load` the tool-result file,
  `base64.b64decode`, write bytes). Don't paste the base64 through the shell.
- Regenerate into a `.new` file:

  ```
  python3 .claude/skills/update-guide-report/scripts/extract_free_channels.py "1.2 Booking channels OTA.xlsx" > data-channels-2026.js.new
  ```

- Compare the grand totals. The new one should be close to the old one, not
  far below:

  ```
  python3 -c "
  import json
  def total(p):
      d = json.loads(open(p).read().split('=',1)[1].rstrip(';\n '))
      return sum(sum(l['all']['byMonth'].values()) for c in d.values() for l in c.values())
  print('old:', total('data-channels-2026.js'))
  print('new:', total('data-channels-2026.js.new'))
  "
  ```

- If the totals look sane:
  `mv data-channels-2026.js.new data-channels-2026.js`, then
  `rm "1.2 Booking channels OTA.xlsx"`. The xlsx is a large binary. Never
  commit it.

**Never touch `data-channels-2025.js`.** 2025 is fixed historical data and is
never regenerated.

### 3. Verify and commit

Open `index.html`. On the Bookings tab's **Free** section, 2026 numbers should
look current and the 2025 values should be unchanged.

```
git add data-channels-2026.js
git commit -m "Update Bookings Free channel data $(date +%Y-%m)"
git push
```

Reload https://jurafst.github.io/freespirit-jura-guide-report/ after about a
minute to confirm it's live.

## Troubleshooting

**`Column "X" not found`**: a column header in one of the sheets was renamed.
Check the sheet's header row against what the error message expects.

**`KeyError: Worksheet Evidencija_25 does not exist`**: the 2025 command is
missing `--sheet Evidencija`. See step 3.

**A guide's numbers look missing or wrong**: their name in the sheet may have
a typo or an extra space compared to earlier exports. Names must match exactly.

**`ModuleNotFoundError: openpyxl`**: run `pip3 install -r .claude/skills/update-guide-report/requirements.txt` again. This
only affects the tour-data script.

## Not covered by this skill

`index.html`, `report.css`, `dist/app.js`, `data-channels-2025.js`. These are
the report's code, styling and frozen 2025 channel data. Don't edit them here.
